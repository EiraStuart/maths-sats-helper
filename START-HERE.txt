TROUBLESHOOTING
━━━━━━━━━━━━━━

❌ "Python not found"
→ Install Python from python.org
→ Check "Add Python to PATH" during setup
→ Restart and try again

❌ Website won't open
→ Try: Right-click index.html → Open with → Your browser
→ Or copy this into your browser address bar:
   file:///C:/Users/Home/maths-sats-helper/index.html

❌ Games not working
→ Make sure all 4 files are in the same folder:
   - index.html
   - styles.css
   - script.js
   - README.md
